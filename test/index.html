Press Run pipeline. It will:

  1. Download the public company registry (~15,900 tokens across three ATS platforms)
  2. Draw a random sample and fetch each company's live jobs
  3. Normalize the three different response shapes into one
  4. Remove duplicates using a normalized company+title+location key
  5. Drop excluded titles, score the rest, and rank them

Expect roughly half the sampled tokens to return 404 — those companies have churned off the platform since the registry was built. That's the number worth watching.
