# JIA — Job Board Aggregator

A personal tool I built during my job search to aggregate listings from multiple ATS platforms (Greenhouse, Ashby, etc.) into a single filtered view.

## Why I built it

Job searching across dozens of company career pages is inefficient. Most companies use the same ATS backends. This tool collects listings by company name and presents them in one place with filtering.

## What it does

- Scrapes/aggregates job listings from Greenhouse, Ashby, and other ATS platforms
- Maintains a company list to search against
- Filters by role, location, and other criteria
- Opens original job board on click for direct application
- Runs on a schedule to keep listings fresh

## Tech Stack

- JavaScript/TypeScript
- Next.js
- Vercel

## Status

Active personal tool. Built to solve my own job search workflow.
